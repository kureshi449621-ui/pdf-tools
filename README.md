# PDF Tools

Free online PDF tools for merging, splitting, compressing, and converting PDF files directly in the browser.

PDFTEQ helps users handle common PDF tasks without installing desktop software. It’s designed for quick file processing on desktop and mobile devices.

Visit the live app: https://pdfteq.com

## Features

- Merge multiple PDF files into one document
- Split large PDFs into smaller files
- Compress PDF files to reduce size
- Convert PDFs to and from common formats
- Secure browser-based workflows
- Works without installing software

## Why use PDF Tools?

Whether you’re working with invoices, contracts, reports, scanned documents, or study materials, PDF Tools makes it easier to manage files quickly and securely.

## Supported workflows

- Merge PDF files
- Split PDF pages
- Compress PDF documents
- Convert PDFs for easier sharing and storage

## How it works

1. Upload your PDF files
2. Choose the action you want to perform
3. Adjust settings if needed
4. Download the processed file

No installation required. Everything runs in the browser.

## Use cases

- Students combining assignments and certificates
- Businesses processing invoices and contracts
- Freelancers organizing documents and portfolios
- Office teams preparing reports and attachments
